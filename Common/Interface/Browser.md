# Browser

このページでは、**UnrealEd** のブラウザ（Browser）について説明します。

ブラウザは、ゲーム内で使用されるさまざまなリソースを管理・選択するためのウィンドウです。

レベル制作では、テクスチャやアクター、サウンドなどを頻繁に使用するため、ブラウザは UnrealEd の中でも特に利用頻度の高い機能の一つです。

---

# Overview

ブラウザは、必要に応じて開いたり閉じたりできる独立したウィンドウです。

利用できるブラウザの種類は UnrealEd のバージョンによって異なりますが、基本的な役割は共通しています。

一般的な作業の流れは以下のようになります。

1. ブラウザを開く
2. 使用したいリソースを選択する
3. レベルへ配置または適用する

---

# Purpose

ブラウザの目的は、ゲームで使用されるリソースを管理し、効率よく利用できるようにすることです。

ブラウザを使用することで、

* パッケージを読み込む
* リソースを検索する
* リソースを選択する
* レベルへ適用する

といった作業を行えます。

---

# Common Browsers

UnrealEd にはさまざまなブラウザがあります。

代表的なものを以下に示します。

## Texture Browser

マップで使用するテクスチャを管理します。

主な用途

* テクスチャの選択
* パッケージの読み込み
* サーフェスへの適用

---

## Actor Browser

レベルに配置できる Actor を管理します。

主な用途

* Actor の検索
* Actor の配置
* クラスの確認

レベル制作では最も頻繁に利用するブラウザの一つです。

---

## Sound Browser

サウンドエフェクトや環境音を管理します。

主な用途

* サウンドの選択
* パッケージの読み込み
* レベルへの配置

---

## Music Browser

BGM を管理します。

主にシングルプレイヤーマップなどで使用されます。

---

## Static Mesh Browser

Unreal Engine 2.5 で利用できるブラウザです。

Static Mesh を選択し、レベルへ配置できます。

このブラウザは Unreal Engine 1 には存在しません。

---

# Packages

ブラウザで扱うリソースは、通常 **Package** に保存されています。

例

* Texture Package
* Sound Package
* Music Package
* Static Mesh Package

必要なパッケージを読み込むことで、対応するリソースを利用できるようになります。

パッケージシステムについては別の章で詳しく解説します。

---

# Version Differences

ブラウザの種類は UnrealEd の世代によって異なります。

**Unreal Engine 1**

* Texture Browser
* Actor Browser
* Sound Browser
* Music Browser

**Unreal Engine 2.5**

* 上記に加えて Static Mesh Browser などが追加されています。

基本的な操作方法は共通しています。

---

# Tips

初めて学習する場合は、以下のブラウザから覚えることをおすすめします。

* Texture Browser
* Actor Browser

この2つだけでも、基本的なレベル制作を始めることができます。

その後、必要に応じて Sound Browser や Static Mesh Browser の使い方を学びましょう。

---

# Notes

ブラウザは UnrealEd の作業効率を大きく左右する重要な機能です。

レベル制作では頻繁に開閉しながら作業を進めるため、それぞれの役割を理解しておくことで、開発をよりスムーズに進められます。
