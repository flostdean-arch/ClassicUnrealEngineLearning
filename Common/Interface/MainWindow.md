# Main Window

このページでは、**UnrealEd** のメインウィンドウについて説明します。

メインウィンドウは、UnrealEd の中心となる作業画面です。レベル制作をはじめ、オブジェクトの配置、ライティング、ビルド、テストプレイなど、ゲーム開発のほぼすべての作業をここから行います。

UnrealEd の基本操作を身につけるためには、まずメインウィンドウの構成と各エリアの役割を理解することが重要です。

---

# Overview

UnrealEd を起動すると、最初にメインウィンドウが表示されます。

UnrealEd には複数のバージョンがありますが、基本的なレイアウトや設計思想は共通しています。

一般的な画面構成は以下のようになります。

```text
+------------------------------------------------------+
| Menu Bar                                             |
+------------------------------------------------------+
| Tool Bar                                             |
+------------------------------------------------------+
|                                                      |
|                  Viewports                           |
|                                                      |
|                                                      |
+------------------------------------------------------+
| Status Bar                                           |
+------------------------------------------------------+
```

また、Texture Browser や Actor Browser などの各種ブラウザは、必要に応じて独立したウィンドウとして表示されます。

---

# Main Components

メインウィンドウは、主に以下の要素で構成されています。

## Menu Bar

ファイル操作や編集、ビルド、各種ツールの起動などを行います。

---

## Tool Bar

よく使用する機能へ素早くアクセスするためのショートカットが配置されています。

---

## Viewports

マップを編集するための作業エリアです。

通常は複数の Viewport を使用して、さまざまな角度からレベルを編集します。

Viewport の詳細については **Common/Viewports** で解説します。

---

## Browser Windows

テクスチャ、サウンド、メッシュ、アクターなどのゲームリソースを管理するためのウィンドウです。

利用できるブラウザの種類は UnrealEd のバージョンによって異なります。

---

## Status Bar

現在の操作状態や選択中のオブジェクトなど、作業に関する情報を表示します。

---

# Typical Workflow

一般的なレベル制作では、メインウィンドウを中心に以下のような流れで作業を進めます。

1. 新しいマップを作成する
2. Viewport でブラシを配置する
3. テクスチャを適用する
4. ライトやアクターを配置する
5. マップをビルドする
6. テストプレイを行う
7. 必要に応じて修正を繰り返す

メインウィンドウは、これらすべての操作の起点となります。

---

# Version Differences

UnrealEd は Unreal Engine の進化に合わせて機能が追加されてきました。

そのため、ボタンの配置やブラウザの種類などには違いがあります。

しかし、以下の基本構成は UnrealEd 1・2・3 に共通しています。

* メニューバー
* ツールバー
* Viewport
* ブラウザウィンドウ
* ステータスバー

一度メインウィンドウの構成を理解すれば、異なるバージョンの UnrealEd にも応用できます。

---

# Notes

初めて UnrealEd を使用する場合は、すべての機能を覚える必要はありません。

まずは、

* 画面全体の構成
* 各エリアの役割
* よく使うウィンドウの位置

を把握することを目標にしましょう。

詳細な操作方法は、以降のドキュメントで順番に解説します。
