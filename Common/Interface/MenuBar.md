# Menu Bar

このページでは、**UnrealEd** のメニューバーについて説明します。

メニューバーは、UnrealEd のすべての機能へアクセスするための入り口です。

新しいマップの作成や保存、編集、ビルド、各種ブラウザの表示など、多くの操作はメニューバーから実行できます。

---

# Overview

メニューバーは、メインウィンドウの最上部に配置されています。

一般的には以下のようなメニューで構成されています。

```text id="vqz4mt"
+--------------------------------------------------------------+
| File | Edit | View | Brush | Build | Tools | Help | ...      |
+--------------------------------------------------------------+
```

表示されるメニューや名称は UnrealEd のバージョンによって多少異なりますが、基本的な役割は共通しています。

---

# File

**File** メニューでは、マップファイルの作成や保存など、ファイルに関する操作を行います。

主な機能

* 新規マップの作成
* マップを開く
* マップを保存する
* 名前を付けて保存する
* マップをインポート・エクスポートする
* UnrealEd を終了する

レベル制作では最も頻繁に利用するメニューの一つです。

---

# Edit

**Edit** メニューでは、編集操作を行います。

主な機能

* 元に戻す（Undo）
* やり直す（Redo）
* コピー
* 貼り付け
* 削除
* オブジェクトの選択

編集作業を効率よく進めるための基本機能がまとめられています。

---

# View

**View** メニューでは、表示方法や各種ウィンドウの表示・非表示を切り替えます。

主な機能

* Viewport の表示設定
* ブラウザの表示
* ツールバーの表示
* 表示モードの変更

作業内容に応じて画面レイアウトを調整できます。

---

# Brush

**Brush** メニューでは、ブラシ（CSG Brush）の操作を行います。

主な機能

* Add
* Subtract
* Deintersect
* Intersect

ブラシ編集は Unreal Engine 1 および Unreal Engine 2.5 のレベル制作における重要な要素です。

詳細については **Common/Brushes** で解説します。

---

# Build

**Build** メニューでは、マップのビルドを実行します。

主な機能

* Geometry のビルド
* BSP の再構築
* Lighting のビルド
* Path のビルド
* すべてのビルド

レベル制作では、変更内容を反映するために頻繁に使用します。

---

# Tools

**Tools** メニューでは、各種ツールやエディタ機能へアクセスできます。

利用できる内容は UnrealEd のバージョンによって異なります。

例

* UnrealScript 関連
* パッケージ管理
* 各種ユーティリティ

---

# Help

**Help** メニューでは、UnrealEd に関する情報やヘルプを表示できます。

バージョンによっては、

* バージョン情報
* ドキュメント
* サポート情報

などが用意されています。

---

# Version Differences

メニューバーの構成は UnrealEd の世代によって多少異なります。

例えば、

* UnrealEd 1
* UnrealEd 2
* UnrealEd 3

では、追加された機能に合わせて新しいメニューや項目が追加されています。

本リポジトリでは、共通する基本的な役割を中心に解説し、各バージョン固有の機能はタイトル別ディレクトリで説明します。

---

# Tips

最初からすべてのメニューを覚える必要はありません。

学習を始めたばかりの段階では、以下のメニューを中心に使用します。

* File
* Edit
* Brush
* Build

これらの基本操作を身につけることで、多くのレベル制作を進められるようになります。
