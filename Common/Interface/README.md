# Interface

このディレクトリでは、**UnrealEd** のユーザーインターフェース（UI）について学びます。

UnrealEd は多くの機能を備えた統合開発環境（IDE）であり、レベル制作からゲームプレイの構築まで、さまざまな作業を一つのアプリケーション上で行うことができます。

効率よく開発を進めるためには、まず UnrealEd の画面構成と各ウィンドウの役割を理解することが重要です。

---

# Purpose

Interface の目的は、UnrealEd の各画面やウィンドウの役割を理解し、基本的な操作に慣れることです。

ここで学ぶ内容は、**Unreal Engine 1** および **Unreal Engine 2.5** のすべての学習内容の基礎となります。

---

このディレクトリでは、主に以下の内容を扱います。

# Learning Order

以下の順番で読み進めることを推奨します。

1. MainWindow
2. MenuBar
3. ToolBar
4. Browser
5. StatusBar

この順番で学ぶことで、UnrealEd 全体の構成を自然に理解できます。

---

# Common Features

UnrealEd のバージョンによって細かな違いはありますが、基本的なインターフェースの考え方は共通しています。

共通する主な要素

* メインウィンドウ
* メニューバー
* ツールバー
* Viewport
* ブラウザ
* ステータスバー

そのため、一度基本操作を覚えれば、異なる UnrealEd のバージョンでも応用できます。

---

# Version Differences

各バージョンには、それぞれ固有の機能や画面構成があります。

例えば、

* UnrealEd 1
* UnrealEd 2
* UnrealEd 3

では、ツールバーやブラウザの種類、利用できる機能などに違いがあります。

これらの違いについては、各タイトル別ディレクトリで必要に応じて解説します。

本ディレクトリでは、複数のバージョンに共通する内容を中心に扱います。

---

# Notes

UnrealEd は機能が非常に豊富ですが、最初からすべてを覚える必要はありません。

まずは、

* 画面のどこに何があるのか
* どのウィンドウが何の役割を持つのか

を理解することを目標にしましょう。

実際の操作方法は、後続の **Viewports** や **Navigation**、**Brushes** などの章で詳しく学びます。
