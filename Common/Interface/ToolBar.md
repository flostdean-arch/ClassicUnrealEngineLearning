# Tool Bar

このページでは、**UnrealEd** のツールバーについて説明します。

ツールバーは、UnrealEd で頻繁に使用する機能へ素早くアクセスするためのショートカットです。

メニューバーからも同じ機能を利用できますが、ツールバーを活用することで作業効率を大きく向上させることができます。

---

# Overview

ツールバーは、通常メニューバーの直下に配置されています。

アイコン形式で各種機能が並んでおり、ワンクリックで操作を実行できます。

一般的な配置例

```text id="wxyhkb"
+--------------------------------------------------------------+
| Menu Bar                                                     |
+--------------------------------------------------------------+
| [New] [Open] [Save] [Undo] [Build] [Play] [Browser] [...]    |
+--------------------------------------------------------------+
```

表示されるアイコンや配置は UnrealEd のバージョンによって異なりますが、基本的な役割は共通しています。

---

# Purpose

ツールバーの目的は、よく使用する機能へ素早くアクセスすることです。

レベル制作では同じ操作を何度も繰り返すため、ツールバーを利用することで作業時間を短縮できます。

---

# Common Functions

ツールバーには、一般的に以下のような機能が配置されています。

## File Operations

ファイル操作に関するショートカットです。

例

* New
* Open
* Save

---

## Edit Operations

編集作業で使用する機能です。

例

* Undo
* Redo
* Cut
* Copy
* Paste

---

## Brush Operations

ブラシ編集を素早く行うための機能です。

例

* Add
* Subtract
* Intersect
* Deintersect

これらは BSP レベル制作において頻繁に使用します。

---

## Build Operations

マップをビルドするための機能です。

例

* Build Geometry
* Build BSP
* Build Lighting
* Build Paths
* Build All

レベル編集後は、変更内容を反映するために定期的にビルドを実行します。

---

## Test Play

現在編集中のマップをテストプレイするための機能です。

作業内容をすぐに確認できるため、レベル制作では頻繁に使用します。

---

## Browser Shortcuts

各種ブラウザを開くためのショートカットです。

例

* Texture Browser
* Actor Browser
* Sound Browser
* Static Mesh Browser（UE2.5）

ブラウザについては **Browser.md** で詳しく解説します。

---

# Version Differences

UnrealEd のバージョンによって、ツールバーの内容は異なります。

例えば、

* UnrealEd 1
* UnrealEd 2
* UnrealEd 3

では、追加された機能に合わせて新しいボタンが配置されています。

一方で、以下の基本機能はほぼ共通しています。

* ファイル操作
* 編集
* ブラシ操作
* ビルド
* テストプレイ

---

# Tips

初めて UnrealEd を使用する場合は、すべてのボタンを覚える必要はありません。

まずは以下の機能を使いこなせるようになりましょう。

* New
* Save
* Undo
* Build
* Play

学習を進めるにつれて、自然と使用するツールが増えていきます。

---

# Notes

ツールバーは、メニューバーの機能をより素早く利用するためのショートカット集です。

基本的な操作はメニューバーからも実行できますが、日常的なレベル制作ではツールバーを活用することで作業効率が向上します。
