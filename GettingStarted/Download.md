# Download

このページでは、**Classic Unreal Engine Learning** で使用するソフトウェアの入手方法について説明します。

本リポジトリでは、**OldUnreal** コミュニティが提供する最新版を標準環境として採用しています。

---

# Supported Titles

本リポジトリで使用するタイトルは以下の3つです。

| Title                    | Engine            | Purpose                    |
| ------------------------ | ----------------- | -------------------------- |
| Unreal Gold              | Unreal Engine 1   | シングルプレイ・Unreal Engine 基礎学習 |
| Unreal Tournament (1999) | Unreal Engine 1   | マルチプレイ・MOD・マップ制作           |
| Unreal Tournament 2004   | Unreal Engine 2.5 | Unreal Engine 2.5 の学習      |

---

# Why OldUnreal?

現在でもクラシック Unreal Engine を学習できる環境はいくつか存在しますが、本リポジトリでは **OldUnreal** 版を推奨しています。

主な理由は以下のとおりです。

* 現代の Windows 環境で安定して動作する
* UnrealEd が利用できる
* コミュニティによる継続的な保守
* 多数のバグ修正
* 高解像度への対応
* 最新レンダラーへの対応

これらの理由から、初めてクラシック Unreal Engine を学習する方にとって最も適した環境となっています。

---

# Download Order

初めて学習する場合は、以下の順番でダウンロードすることを推奨します。

1. Unreal Gold
2. Unreal Tournament (1999)
3. Unreal Tournament 2004

Unreal Gold で Unreal Engine の基本を学び、その後 Unreal Tournament シリーズへ進むことで、段階的に理解を深められます。

---

# Unreal Gold

Unreal Engine 1 の基本を学ぶためのタイトルです。

主に以下の内容を学習します。

* UnrealEd
* シングルプレイヤーマップ制作
* Trigger
* ScriptedPawn
* イベント
* レベル構築

---

# Unreal Tournament (1999)

Unreal Engine 1 のマルチプレイ機能を学ぶためのタイトルです。

主に以下の内容を学習します。

* DeathMatch
* Capture the Flag
* Domination
* Assault
* Bot Path
* Mutator

---

# Unreal Tournament 2004

Unreal Engine 2.5 を学ぶためのタイトルです。

主に以下の内容を学習します。

* Karma Physics
* Vehicle
* GUI
* Onslaught
* UnrealScript
* 高度なマップ制作

# Notes

本リポジトリは **OldUnreal** 版を前提として作成されています。

Steam 版や GOG 版などを利用している場合でも学習内容の多くは共通していますが、画面表示や設定方法、利用できる機能が一部異なる場合があります。

そのため、本リポジトリでは OldUnreal 版を使用することを推奨します。
