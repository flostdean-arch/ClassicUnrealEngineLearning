# First Launch

このページでは、**Classic Unreal Engine Learning** の学習を始める前に、ゲームおよび **UnrealEd** が正常に動作することを確認します。

インストールが完了したら、まず各タイトルを一度起動し、問題なく利用できることを確認しましょう。

---

# Before You Begin

このページを読む前に、以下が完了していることを確認してください。

* **SystemRequirements.md** を確認済み
* **Download.md** を確認済み
* **Installation.md** の手順に従ってインストール済み

---

# First Game Launch

まずはインストールしたゲームを起動します。

初回起動時には、ゲームが各種設定ファイル（INI ファイル）を自動的に生成します。

起動後は以下の項目を確認してください。

* タイトル画面が正常に表示される
* エラーメッセージが表示されない
* BGM や効果音が再生される
* キーボード・マウスが正常に動作する
* ゲームが終了せず安定して動作する

ここでは実際にゲームをプレイする必要はありません。

正常に起動できることを確認できれば十分です。

---

# Configuration Files

初回起動時には、各タイトルの **System** フォルダ内に設定ファイル（INI ファイル）が作成されます。

これらのファイルには、ゲームや UnrealEd の各種設定が保存されます。

主な設定内容

* 画面設定
* オーディオ設定
* 入力設定
* レンダラー設定
* UnrealEd の設定

今後の学習では、INI ファイルを編集する場面もあります。

---

# Launch UnrealEd

次に **UnrealEd** を起動します。

初回起動では設定ファイルの作成などが行われるため、通常より時間がかかる場合があります。

以下の項目を確認してください。

* UnrealEd が正常に起動する
* メインウィンドウが表示される
* 4つの Viewport が表示される
* メニューやツールバーが表示される
* エラーダイアログが表示されない

UnrealEd の操作方法については **UnrealEd.md** で詳しく解説します。

---

# Verify the Rendering

ゲーム画面および UnrealEd の Viewport が正常に描画されることを確認してください。

以下のような症状が発生する場合は、レンダラーやグラフィックス設定を確認してください。

* 画面が真っ黒になる
* 描画が乱れる
* テクスチャが表示されない
* Viewport が更新されない

問題が発生した場合は **Troubleshooting.md** を参照してください。

---

# Verify the Installation

最後に、以下のチェックリストを確認しましょう。

* □ ゲームが正常に起動する
* □ タイトル画面が表示される
* □ 設定ファイル（INI）が生成されている
* □ UnrealEd が正常に起動する
* □ Viewport が正しく表示される
* □ エラーメッセージが表示されない

すべて確認できれば、学習環境の準備は完了です。
