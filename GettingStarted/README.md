# Getting Started

このディレクトリでは、**Classic Unreal Engine Learning** を始めるための準備について解説します。

初めてクラシック版 Unreal Engine に触れる方は、このディレクトリから読み進めることを推奨します。

---

# このディレクトリで学べること

Getting Started では、学習環境の構築と初期設定を扱います。

主な内容は以下のとおりです。

* 学習に必要なソフトウェア
* 対応タイトルの入手方法
* インストール方法
* UnrealEd の起動方法
* 初回起動時の設定
* ディレクトリ構成
* よくあるトラブルと対処方法

---

# 学習の流れ

このリポジトリでは、以下の順番で学習を進めることを推奨します。

```text
Getting Started
        ↓
      Common
        ↓
   Unreal Gold
        ↓
Unreal Tournament (1999)
        ↓
Unreal Tournament 2004
```

まずは開発環境を構築し、その後 UnrealEd の基本操作を学びます。

Unreal Gold ではシングルプレイヤーマップ制作を通して Unreal Engine の基礎を学び、その知識を Unreal Tournament (1999) のマルチプレイヤーマップ制作へ応用します。

最後に Unreal Tournament 2004 を用いて、Unreal Engine 2.5 の新機能や発展的なゲーム制作を学びます。

---
