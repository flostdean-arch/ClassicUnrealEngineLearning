# System Requirements

このページでは、**Classic Unreal Engine Learning** を学習するために必要な動作環境について説明します。

本リポジトリでは、**OldUnreal** コミュニティが提供する Unreal Gold、Unreal Tournament (1999)、Unreal Tournament 2004 を標準的な学習環境として採用しています。

これらは現代の Windows 環境向けにメンテナンスされており、クラシック Unreal Engine を学習するための最も利用しやすい環境です。

---

# Supported Operating Systems

以下のオペレーティングシステムでの利用を推奨します。

* Windows 10 (64-bit)
* Windows 11 (64-bit)

他の OS でも動作する場合がありますが、本リポジトリでは Windows 環境を前提として解説します。

---

# Hardware Requirements

クラシック Unreal Engine は1998〜2004年頃に開発されたゲームエンジンです。

現在一般的に利用されている PC であれば、性能不足を心配する必要はほとんどありません。

| Component | Recommended          |
| --------- | -------------------- |
| CPU       | 64-bit Processor     |
| Memory    | 4 GB RAM 以上（8 GB 推奨） |
| Graphics  | DirectX 11 対応 GPU    |
| Storage   | 5 GB 以上の空き容量         |
| Display   | 1920×1080 以上推奨       |

オンボード GPU でも快適に動作します。

# Required Software

学習には以下のソフトウェアを推奨します。

## Required

* Unreal Gold
* Unreal Tournament (1999)
* Unreal Tournament 2004

## Recommended

* Visual Studio Code などのテキストエディタ
* Git
* GitHub Desktop

テキストエディタは UnrealScript の編集や設定ファイルの確認に使用します。

Git を利用すると、学習内容や作成したマップ、スクリプトを安全に管理できます。

# Internet Connection

以下の用途のため、インターネット接続を推奨します。

* 対象タイトルのダウンロード
* コミュニティパッチの入手
* ドキュメントの閲覧

一度環境を構築すれば、多くの学習内容はオフラインでも進められます。

| Title                    | Engine            |

---

# Why OldUnreal?

OldUnreal は、クラシック Unreal Engine シリーズの保守・改善を目的としたコミュニティプロジェクトです。

本リポジトリでは、以下の理由から OldUnreal 版を推奨しています。

* 現代の Windows 環境への対応
* 多数のバグ修正
* 高解像度への対応
* 最新のレンダラーへの対応
* UnrealEd の安定性向上
* コミュニティによる継続的なサポート

学習内容の多くはオリジナル版にも応用できますが、初めて学習する方には OldUnreal 版の利用を推奨します。
