# Classic Unreal Engine Learning

### *A Japanese Learning Resource for Unreal Engine 1 & Unreal Engine 2.5*

Classic Unreal Engine Learning は、**Unreal Engine 1** および **Unreal Engine 2.5** を体系的に学ぶための日本語学習リポジトリです。

本リポジトリでは、クラシック版 Unreal Engine の開発環境を利用し、**UnrealEd** によるマップ制作、**UnrealScript** によるプログラミング、ゲームプレイ構築、MOD 開発などを実践的に学ぶことを目的としています。

また、本リポジトリは「ゲームエンジンの使い方」に焦点を当てています。

ゲームエンジンの歴史や設計思想、内部構造などについては、姉妹リポジトリ **VideoGameTechnologyHeritage** を参照してください。

---

# Purpose

このリポジトリは、以下のような方を対象としています。

* Unreal Engine 1 を学びたい方
* Unreal Engine 2.5 を学びたい方
* UnrealEd の使い方を学びたい方
* UnrealScript を学びたい方
* Unreal Tournament の MOD 制作に興味がある方
* クラシックゲームエンジンを研究したい方

## UnrealGold

**Unreal Gold** を利用した Unreal Engine 1 の学習コンテンツです。

シングルプレイヤーゲーム制作を中心に、Unreal Engine の基本的な仕組みを学びます。

主な内容

* レベル制作
* Trigger
* ScriptedPawn
* Inventory
* Event
* シングルプレイゲーム構築

---

## UnrealTournament99

**Unreal Tournament (1999)** を利用した Unreal Engine 1 の学習コンテンツです。

マルチプレイヤーマップ制作やゲームタイプの作成について学びます。

主な内容

* DeathMatch
* Capture the Flag
* Domination
* Assault
* Bot Path
* Mutator
* Multiplayer Mapping

---

## UnrealTournament2004

**Unreal Tournament 2004** を利用した Unreal Engine 2.5 の学習コンテンツです。

UE2.5 の拡張機能や、より高度なゲーム制作について解説します。

主な内容

* Karma Physics
* Vehicles
* GUI
* Onslaught
* Assault
* UnrealScript
* Advanced Mapping

---

# Recommended Learning Order

初めて学習する方は、以下の順番で進めることを推奨します。

1. **Common**
2. **Unreal Gold**
3. **Unreal Tournament (1999)**
4. **Unreal Tournament 2004**

まず Unreal Gold でシングルプレイヤーマップ制作を通して Unreal Engine の基本を学び、その後 Unreal Tournament でマルチプレイ向けのマップ制作を学習します。

最後に Unreal Tournament 2004 を通して Unreal Engine 2.5 の新機能や発展的な内容を学ぶことで、クラシック Unreal Engine を段階的に理解できます。

* **ClassicUnrealEngineLearning** では「どのように使うか」

をそれぞれ解説します。
